# 規約チェッカー

このファイルは規約チェッカーの実装・回帰テストの正本とする。自動チェックと人のレビューの共通方針は[共通規約](../../RULES.md#自動チェックと人のレビュー)、テスト実行時の保護は[testsの規約](../../tests/RULES.md)に従う。

- 規約チェック用のスクリプトはこのディレクトリに置く。チェッカーの回帰テストとPythonの構成テストは[共通のテスト配置](../../RULES.md#テストの配置)に従う。
- 規約チェックはASTや既存ツールを使う。ソース全文への単純な文字列検索だけでimportや構文を判定しない。
- 新しいルールには、違反例を拒否し正常例を受け入れるテストを付ける。規約に穴が見つかったら、まず違反を再現する小さなテストを追加し、チェックを直す。
- ルールIDと対応するRULES.mdを揃え、自動で判定できない部分は人のレビューと明記する。
- 自動修正で利用者コードを削除したり、チェックを黙って弱めたりしない。
