# tests

このファイルはテスト設計・実行時の保護・成果物の取得方法の正本とする。配置と結果保存先は[共通規約のテストの配置](../RULES.md#テストの配置)、Pythonのプロセス・import起点の分離は[開発環境の配置](../RULES.md#開発環境の配置)に従う。

- テストは公開される振る舞い・失敗条件・境界を確認する。実装をそのまま写すテストや、軽微な文言変更だけのテストを増やさない。
- エラー表示のテスト以外では、実際の境界をmockで置き換えない。
- テスト自身が起動したプロセスを必ず終了する。既存の利用者プロセスをkillしない。
- テストには一時データ・テスト専用DBを使い、利用者本人のファイル・設定・DBを変更しない。
- Playwrightのスクリーンショットは`test.info().outputPath()`を使う。
- 実機で試していないOSを対応済みと書かない。

担当固有の構成と実行方法は、[Web E2E](../frontend/RULES.md#テスト)、[Electronのテスト](../native/RULES.md#テスト)、[backendの完了確認](../backend/RULES.md#完了確認)、[MCPのテスト](../mcp/RULES.md#テスト)を参照する。規約違反を注入するテストは[規約チェッカーの規約](../scripts/rules/RULES.md)に従う。
